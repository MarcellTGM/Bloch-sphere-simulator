1. Projektleírás

A Bloch-gömb szimulátor egy teljes mértékben böngészőben futó interaktív webalkalmazás, amely lehetővé teszi az egyqubites kvantumállapotok szimulációját, vizualizációját és manipulációját. A program a Bloch-gömb geometriai reprezentációját használja az állapotok megjelenítésére.

1.1 Feladat megfelelés

  • ✓ Webalkalmazás: Böngészőben futó Blazor WebAssembly
  • ✓ Qubit állapot kezelés: Komplex amplitúdók szimulációja
  • ✓ Kvantumkapuk: 10+ logikai kapu (Pauli, Hadamard, forgatások)
  • ✓ Kapu láncolat: Sorba fűzés és lépésenkénti vagy teljes alkalmazás
  • ✓ Bloch-gömb: 3D interaktív vizualizáció Plotly.js-sel
  • ✓ Állapotkezelés: Több állapot mentése és összehasonlítása
  • ✓ Felhasználói élmény: Intuitív, professzionális UI

2. Funkciók és Használati Útmutató

2.1 Kezdőállapot beállítása

Gyors alapállapot kiválasztás: A legördülő menüből 6 előre definiált állapot közül lehet választani:

  • |0⟩ – alapállapot (θ = 0°, φ = 0°)
  • |1⟩ – gerjesztett állapot (θ = 180°, φ = 0°)
  • |+⟩ – szuperponálás az X tengely mentén (θ = 90°, φ = 0°)
  • |-⟩ – szuperponálás a −X tengely mentén (θ = 90°, φ = 180°)
  • |+i⟩ – szuperponálás az Y tengely mentén (θ = 90°, φ = 90°)
  • |-i⟩ – szuperponálás a −Y tengely mentén (θ = 90°, φ = 270°)

Tetszőleges állapot beállítása: Az állapot a Bloch-gömbön az alábbi formulával reprezentálódik:

|ψ⟩ = cos(θ/2)|0⟩ + eiφsin(θ/2)|1⟩

ahol θ (polár szög) 0 és π között, φ (azimut szög) 0 és 2π között lehet.

Aktuális állapot megjelenítése: Az alkalmazás megjeleníti az állapot komplex amplitúdóit:

|ψ⟩ = [α, β]
α = cos(θ/2), β = eiφ sin(θ/2)

2.2 Logikai kapuk és kapu-sor

Pauli-kapuk: I, X, Y, Z

Speciális kapuk: H (Hadamard), S (Fáziskapu), T (π/8 fáziskapu)

Forgatási kapuk: Rx(θ), Ry(θ), Rz(θ)

Kapuk alkalmazása:

  • Lépésenkénti alkalmazás: Az "Következő alkalmazása" gomb az első kaput alkalmazza
  • Teljes alkalmazás: Az "Összes alkalmazása" gomb az összes kaput egyszerre futtatja

2.3 Pillanatképek (State Snapshots)

  • Azonosító: Az állapot neve
  • Szín: Tetszőleges szín választása
  • Mentés: Az aktuális állapot és annak Bloch-koordinátáit elmenti
  • Összes törlése: Az összes mentett pillanatképet törli

2.4 Bloch-gömb 3D vizualizáció

Interakciók:

  • Bal klikk + húzás: A gömb forgatása
  • Görgetés: Nagyítás és kicsinyítés
  • Jobb klikk + mozgás: 3D térben való mozgatás
  • Egér lebegés: Az állapot Bloch-koordinátái megjelennek

Bloch-koordináták:

x = 2·Re(α*β), y = 2·Im(α*β), z = |α|² - |β|²

3. Technikai Implementáció

3.1 Architektura

  • Frontend (Razor Components): Interaktív UI, valós idejű frissítés
  • Backend (QuantumService): Kapu mátrixok, állapotmanipuláció
  • Vizualizáció (Plotly.js): 3D gömb, interaktív kontrollerek

3.2 Kvantumállapot kezelés

Minden qubit állapot 2D komplex vektorként reprezentálódik:

|ψ⟩ = [α, β], |α|² + |β|² = 1

3.3 Kapu alkalmazás

|ψ'⟩ = U|ψ⟩ (Mátrix-vektor szorzás)

7. Függelék: Matematikai Összefoglalás

A.1 Qubit alapok

A qubit egy kvantumrendszer alapegysége:

|ψ⟩ = α|0⟩ + β|1⟩, |α|² + |β|² = 1

A.2 Bloch-gömb reprezentáció

Az (x, y, z) koordináták a qubit állapotokat reprezentálják:

(x, y, z) = (2Re(α*β), 2Im(α*β), |α|² - |β|²)

A.3 Unitér transzformációk

Kvantumműveletek unitér mátrixok által reprezentálódnak:

|ψ'⟩ = U|ψ⟩, ahol U†U = I
